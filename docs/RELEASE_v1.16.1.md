# v1.16.1-alpha.1 — Yarden testing

- Experimental Mountain Tower + Ruin of Hunters and Ruin Tower + Old Garden of
  Storms endings, with cumulative earlier-region checks.
-49 Yarden soul orbs from verified native-field membership. Both endings select
 137 orbs in total:215 Mountain checks or219 Ruin checks with orbs enabled.
- Immediate map markers for selected Yarden orbs; collected/checked markers use
 the existing grey state. Orb rewards remain non-progression.
- Additive milestone catalog and preserved earlier-session mappings.

New selections require a newly generated seed. Existing AP records and saves
must be retained. Do not enroll an advanced character in a new playthrough slot.
Advanced-character diagnostic captures can be taken without connecting to AP.

Yarden is experimental: saved dungeon/tower states have been captured, while new
completion-event/AP delivery tests and combat balancing remain pending. Keep stool
production enabled for the modeled saltpeter route. See YARDEN_RUNS.md for details.

This build is prepared for local testing, not a claim of public release or Workshop
publication. If Workshop supplies an older copy, use `Install-Mod.ps1 -Mode Manual`
from this package with the game closed to install this exact bundled version.
