# Workshop distribution retired

The Steam Workshop listing was made private on October 29, 2026. Installations and updates are now distributed through [GitHub Releases](https://github.com/Akamarus/craftopia-archipelago/releases).

Download and extract the Windows ZIP, close Craftopia, and run **Install Bundled Build.cmd**. This selects the bundled release and prevents a downloaded Workshop copy from loading alongside it. Avoid the legacy automatic `Setup.cmd`, which can select an older Workshop copy.

Saves and AP progress records are preserved. See the [installation guide](INSTALLATION.md).

Historical Workshop tooling and compatibility handling remain in source for maintenance of older installations.
