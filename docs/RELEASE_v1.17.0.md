# Craftopia Archipelago 1.17.0 release candidate

This candidate extends cumulative runs through Owatatsu Archipelago and
Brigandine Valley. The combined Brigandine run contains330 checks with orbs enabled
and ends with Brigandine Tower completion plus Old Garden of Massacre.

The matching mod, managed bridge and APWorld are included. Extract the complete
Windows ZIP, close Craftopia, and run **Install This Test Build.cmd** to install
this exact candidate even when an older Workshop copy exists. The installer
preserves AP records and saves and retains rollback backups. Read INSTALLATION.md.

New content: six tower stages, two main dungeons, Age5 advancement and102 native
regional soul orbs. Older selected seed contracts remain unchanged.

This is not yet a published official release. See VALLEY_RUNS.md for source evidence,
combat assumptions and the targeted live checks still required. Multiplayer remains
experimental pending a host/guest test. The new seed is prepared separately; installing
this build does not switch your slot or enroll a character.
